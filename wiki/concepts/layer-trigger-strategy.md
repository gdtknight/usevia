# 🎯 레이어 트리거 전략 (Thumb + Bottom-Row LT)

36키 스플릿 키보드에서 9개 레이어를 오타 없이 빠르게 넘나들기 위해 채택한 **트리거 배치 전략**과 설계 근거를 정리합니다.

---

## 1. 왜 Home Row Mods(HRM) 대신 하단 열 + 엄지인가?

많은 34~36키 키맵(예: Miryoku)이 홈 로우(`A, S, D, F` / `J, K, L, ;`)에 `Ctrl, Opt, Cmd, Shift` Mod-Tap을 배치하지만, 실사용(특히 **한국어/영어 혼용 고속 타이핑**)에서는 다음과 같은 문제가 자주 발생합니다:

1. **한글 자모 롤오버(Rollover) 오작동**: 한글은 자음(`ㅁ, ㄴ, ㅇ, ㄹ`)과 모음(`ㅓ, ㅏ, ㅣ`)이 홈 로우에 밀집되어 있어, 빠르게 연타할 때 의도치 않게 `Cmd`나 `Ctrl` 단축키가 발동되는 현상(Misfire)이 잦습니다.
2. **VIA 환경에서의 Tapping Term 세부 튜닝 한계**: QMK 소스 직접 컴파일과 달리 VIA JSON 설정만으로는 키별 `PERMISSIVE_HOLD`, `ACHORDION` 같은 정교한 HRM 보정 옵션을 다르게 주기 어렵습니다.

### ✅ 해결책: 수식키는 왼손 엄지에 고정 + 보조 레이어는 하단 열(`Z, X, C, V, M`)에 배치

- **수식키(`⌃, ⌥, ⌘`)의 완전 분리**: 왼손 엄지 3키(Index `17, 18, 19`)에 물리적 수식키를 고정하여 타이핑 중 오작동 확률을 **0%**로 만들었습니다.
- **Shift의 이중화**:
  - 일반 타이핑 시: 오른손 하단 끝 `KC_SFTENT`(Index `30`)를 홀드하여 `Shift`로 사용 (탭 시 `Enter`).
  - 기호 입력 시: Shift를 따로 누를 필요 없이 오른손 중간 엄지([[layer-2-shift-sym|Layer 2]])가 모든 Shift 기호를 즉시 출력.
  - 방향키/범위 선택 시: [[layer-1-nav-num-sym|Layer 1]], [[layer-2-shift-sym|Layer 2]], [[layer-7-numpad|Layer 7]]의 왼손 하단 첫 키(Index `10`)에 일반 `KC_LSFT`를 배치해 `Shift + 방향키` 블록 지정을 지원.
- **하단 열(`Z, X, C, V, M`) Layer-Tap 활용**:
  - 홈 로우보다 타이핑 빈도가 상대적으로 낮고 연타 간격이 명확한 하단 열에 앱·상황별 전용 레이어(`L4~L8`)를 배정했습니다.

## 2. 양손 역할 분담 원칙 (Opposite-Hand / Cross-Finger Principle)

하단 열 키를 홀드(`Hold`)한 상태에서 같은 손으로 다른 키를 누를 때의 인체공학적 기준입니다:

| 트리거 키 | 진입 레이어 | 홀드하는 손가락 | 주 작업 손 | 동선 설계 특징 |
| :--- | :--- | :---: | :---: | :--- |
| `Spc` (`LT(1)`) | [[layer-1-nav-num-sym\|Layer 1]] | 오른손 안쪽 엄지 | **양손 전체** | 엄지만 누르고 있으므로 양손 30키 모두 자유롭게 사용 |
| `Ent` (`LT(2)`) | [[layer-2-shift-sym\|Layer 2]] | 오른손 중간 엄지 | **양손 전체** | L1과 동일한 근육 기억으로 모든 Shift 기호 접근 |
| `MO(3)` | [[layer-3-mouse-media\|Layer 3]] | 오른손 바깥 엄지 | **양손 (고정 시 한 손)** | `TO(3)` 고정 기능으로 엄지 홀드 부담 없이 마우스 조작 가능 |
| `Z` (`LT(4)`) | [[layer-4-browser-edit\|Layer 4]] | 왼손 새끼 (`2,0`) | **왼손 검지·중지 / 오른손 전체** | 왼손 상단(`Q,W,E,R,T`)은 한 손 브라우저 제어, 오른손은 커서 이동 |
| `X` (`LT(5)`) | [[layer-5-ide-coding\|Layer 5]] | 왼손 약지 (`2,1`) | **오른손 중심 + 왼손 검지·중지** | 코드 이동(`F12`), 주석(`⌘/`), 줄 이동, 디버그(`F5~F11`)를 오른손에 집중 |
| `C` (`LT(6)`) | [[layer-6-hyper-meh\|Layer 6]] | 왼손 중지 (`2,2`) | **오른손(`Meh`) + 왼손(`Hyper`)** | 창 분할(`Meh+방향키`)은 오른손에서, 앱 런처(`Hyper`)는 왼손에서 실행 |
| `V` (`LT(7)`) | [[layer-7-numpad\|Layer 7]] | 왼손 검지 (`2,3`) | **오른손 전체 (3×3 넘패드)** | 왼손 검지로 `V`만 누르면 오른손이 완전한 독립 계산기로 변신 |
| `B` (`LT(8)`) | [[layer-8-macos-system\|Layer 8]] | 왼손 안쪽 검지 (`2,4`) | **왼손/오른손 전체** | 왼손 하단 5키(`Z,X,C,V,B`)가 L4~L8로 완벽히 일렬 정렬되어 멘탈 모델 일원화 |

---

## 3. 향후 개선 및 실험 후보 (Open Ideas)

- **왼손 하단 `Z(L4)` 홀드 상태에서 `Q(⌘W)` 누르기**:
  - 둘 다 왼손 바깥쪽(새끼~약지)에 위치하므로, 만약 손가락이 꼬이는 느낌이 든다면 `Z` 홀드 시 자주 쓰는 탭 닫기/전환 키를 검지·중지 쪽(`E, R, T, D, F, G`)이나 오른손으로 옮기는 튜닝을 고려할 수 있습니다.
- **오른손 미사용 하단 키 `N`(오른손 `6,4`) 및 `M`(오른손 `6,3`) 활용**:
  - L8 트리거가 왼손 `B`로 이동하면서 오른손 `M`이 일반 영문키로 복귀하여, 향후 특수 매크로나 커스텀 단축키 슬롯으로 여유롭게 활용할 수 있습니다.
