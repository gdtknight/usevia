# 🔧 X.Tips X7 하드웨어 매트릭스 및 VIA 제약사항

이 문서는 [via-x7.json](file:///Users/yong/Documents/UseVia/via-x7.json)과 [x_tips_x7_keyboard.layout.json](file:///Users/yong/Documents/UseVia/x_tips_x7_keyboard.layout.json)의 물리적 스위치 배선 구조와 QMK/VIA 키코드 제약사항을 정의합니다. 키맵 JSON을 직접 수정하거나 분석할 때 반드시 참조해야 합니다.

---

## 1. 하드웨어 기본 제원

- **모델명**: X.Tips X7 Keyboard
- **Vendor ID / Product ID**: `0x5262` / `0x4E4B` (`vendorProductId: 1382174283`)
- **물리적 키 수**: 총 **36키** (좌/우 각 3행×5열 알파벳 영역 + 3키 엄지 클러스터)
- **매트릭스 정의**: `8 rows × 5 cols = 40 slots` (레이어당 40개 키코드 배열, 미사용 슬롯 4개는 `KC_NO`)

## 2. 물리적 배치 ↔ JSON 배열 인덱스 매핑표

> [!WARNING]
> **오른손(Rows 4~7) 인덱스 역순 주의**:
> X.Tips X7의 PCB 배선 특성상, 오른손은 **바깥쪽(새끼손가락, Col 0)부터 안쪽(검지, Col 4)** 순서로 JSON 배열에 저장됩니다. 따라서 화면에 보이는 **왼쪽 → 오른쪽** 물리적 순서로 읽으려면 오른손 행은 인덱스를 **역순(`24→20`, `29→25`, `34→30`, `39→37`)**으로 매핑해야 합니다.

## 3. QMK / VIA 키코드 기술적 제약사항

1. **`LT(layer, kc)` 및 `MT(mod, kc)`의 8비트 키코드 제한**
   - QMK 펌웨어에서 Layer-Tap(`LT`)과 Mod-Tap(`MT`)의 두 번째 인자(`kc`, 짧게 탭했을 때 입력되는 키)는 **기본 키코드(`0x00 ~ 0xFF`)만 허용**합니다.
   - 예를 들어 `LT(1, G(KC_C))`나 `LT(2, KC_EXLM)`(= `S(KC_1)`)처럼 수식키가 결합된 16비트 키코드를 넣으면 탭 동작이 깨집니다.
   - 현재 레이아웃의 모든 `LT` 키(`KC_Z`, `KC_X`, `KC_C`, `KC_V`, `KC_M`, `KC_SPC`, `KC_ENT`)와 `KC_SFTENT`(`LSFT_T(KC_ENT)`)는 이 규칙을 준수합니다.
2. **VIA JSON 파서의 정식 키코드 표기 규칙 (Export 포맷 기준)**
   - **마우스 휠 키코드**:
     - VIA GUI에서 마우스 휠을 할당하고 Export하면 `KC_WH_U` 대신 **`KC_MS_WH_UP`**, **`KC_MS_WH_DOWN`**, **`KC_MS_WH_LEFT`**, **`KC_MS_WH_RIGHT`**로 저장됩니다.
     - `KC_WH_U` 같은 약어는 웹 VIA에서 파싱되지 않아 키 할당이 빈 상태로 누락됩니다.
   - **수식키 결합 표기**:
     - `Shift + GUI`: VIA에서는 **`LSG(...)`**로 정규화되어 저장됩니다.
     - `Ctrl + Alt`: VIA에서는 **`LCA(...)`**로 저장됩니다.
     - `Ctrl + Alt + GUI`: VIA에서는 **`LCAG(...)`**로 저장됩니다.
   - **Shift 기호 표기**:
     - VIA Export 시 `KC_EXLM`, `KC_AT` 대신 기본 키에 Shift를 씌운 **`S(KC_1)`**, **`S(KC_2)`** 형태로 정규화됩니다.
3. **macOS 한/영 전환과 `KC_CAPS`**
   - macOS의 'Caps Lock 키로 ABC 입력 소스 전환' 기능을 활용하기 위해 [[layer-0-base|Layer 0]] 오른손 하단 4열(Index `31`)에 `KC_CAPS`를 배치했습니다.
3. **사전 정의된 매크로 슬롯 (`macros[0..15]`)**
   - 현재 [x_tips_x7_keyboard.layout.json](file:///Users/yong/Documents/UseVia/x_tips_x7_keyboard.layout.json)에는 0~4번 매크로(`⌘X`, `⌘C`, `⌘V`, `⌘Tab`, `⌘⇧Tab`)가 정의되어 있으나, 실제 레이어에서는 매크로 대신 반응 속도가 빠르고 안정적인 QMK 네이티브 단축키 키코드(`G(KC_X)`, `G(KC_C)`, `G(KC_V)` 등)를 직접 사용하고 있습니다. 향후 복합 문자열 입력이나 다단계 시퀀스가 필요할 때 매크로 슬롯(`M0`~`M15`)을 활용할 수 있습니다.
