# 🌐 브라우징 및 고속 텍스트 편집 워크플로우

왼손 하단 `Z` 홀드([[layer-4-browser-edit|Layer 4]])와 오른손 엄지 `Space` 홀드([[layer-1-nav-num-sym|Layer 1]])를 결합해 웹 서핑과 문서 편집 속도를 높이는 워크플로우입니다.

---

## 1. 오른손 마우스 + 왼손 원핸드 브라우징

오른손으로 트랙패드나 마우스를 잡고 있을 때, **왼손 하나만으로(`Z` 홀드)** 브라우저의 모든 탭과 히스토리를 제어할 수 있습니다.

- **탭 제어 (왼손 상단)**:
  - `Z + Q` (`⌘W`): 현재 탭 닫기
  - `Z + W` (`⌘⇧T`): 방금 닫은 탭 다시 열기
  - `Z + E` (`⌘T`): 새 탭 열기
  - `Z + R` (`⌘R`): 새로고침
  - `Z + T` (`⌘L`): 주소창(URL 바) 선택
- **탭 전환 및 히스토리 (왼손 중단)**:
  - `Z + D` (`⌘⇧[`) / `Z + F` (`⌘⇧]`): 왼쪽 / 오른쪽 탭으로 전환
  - `Z + S` (`⌘[`) / `Z + G` (`⌘]`): 웹페이지 뒤로 / 앞으로 가기
- **숫자 탭 직행 점프 ([[layer-1-nav-num-sym|Layer 1]])**:
  - 왼손 엄지 `Cmd` + 오른손 엄지 `Spc(L1)` + 상단 `1~9` = `⌘1 ~ ⌘9` (원하는 번호의 탭으로 즉시 이동)

---

## 2. 단어·줄 단위 고속 커서 이동 및 삭제

긴 문장이나 코드를 수정할 때 방향키를 여러 번 연타하지 않고 [[layer-4-browser-edit|Layer 4]]의 오른손 홈 로우를 사용합니다.

| 동작 | 단축키 조합 (`Z` 홀드 + 오른손) | 실제 출력 키코드 |
| :--- | :--- | :---: |
| **줄 맨 앞으로 이동** | `Z` + `H` (오른손 검지 안쪽) | `⌘ + ←` |
| **한 단어 왼쪽으로 이동** | `Z` + `J` (오른손 검지) | `⌥ + ←` |
| **한 단어 오른쪽으로 이동** | `Z` + `K` (오른손 중지) | `⌥ + →` |
| **줄 맨 끝으로 이동** | `Z` + `L` (오른손 약지) | `⌘ + →` |
| **앞 단어 통째로 삭제** | `Z` + `Bksp` (오른손 새끼) | `⌥ + ⌫` |
| **앞 줄 전체 삭제** | `X(L5)` + `Bksp` (오른손 새끼) | `⌘ + ⌫` |
