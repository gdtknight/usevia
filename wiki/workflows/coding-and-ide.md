# 💻 코딩 및 IDE 워크플로우

36키 스플릿 키보드로 프로그래밍할 때 가장 큰 장벽인 **특수기호 입력**과 **IDE 복합 단축키**를 [[layer-1-nav-num-sym|Layer 1]], [[layer-2-shift-sym|Layer 2]], [[layer-5-ide-coding|Layer 5]]의 조합으로 해결하는 실전 가이드입니다.

---

## 1. 괄호 및 연산자 근육 기억 (Muscle Memory)

오른손 엄지 두 개(`Space=L1`, `Enter=L2`)만 번갈아 누르면 손가락 위치 이동 없이 모든 괄호와 기호가 완성됩니다.

| 기호 그룹 | 입력 방법 | 손가락 동선 |
| :--- | :--- | :--- |
| **대괄호 `[ ]`** | `Spc(L1)` 홀드 + 오른손 **`J` / `K`** | 오른손 홈 로우 검지·중지 |
| **중괄호 `{ }`** | `Ent(L2)` 홀드 + 오른손 **`J` / `K`** | 대괄호와 **정확히 같은 자리** (엄지만 변경) |
| **소괄호 `( )`** | `Ent(L2)` 홀드 + 오른손 **`O` / `P`** | 숫자 `9, 0` 자리와 동일 (오른손 상단 약지·새끼) |
| **화살표 함수 `=>`** | `Spc(L1)` + 왼손 `G`(`=`) → `Ent(L2)` + 오른손 `.`(`>`) | 왼손 안쪽 검지 → 오른손 약지 |
| **언더스코어 `_` / 대시 `-`** | `Spc(L1)` + 왼손 **`F`** (`-`) / `Ent(L2)` + 왼손 **`F`** (`_`) | 가장 힘센 왼손 검지 홈 로우(`F`)에서 `-`와 `_` 모두 해결 |
| **세미콜론 `;` / 콜론 `:`** | `Spc(L1)` + 오른손 **`H`** (`;`) / `Ent(L2)` + 오른손 **`H`** (`:`) | 오른손 검지 안쪽(`H`) |
| **작은/큰따옴표 `' "`** | `Spc(L1)` + 오른손 **`N`** (`'`) / `Ent(L2)` + 오른손 **`N`** (`"`) | 오른손 하단 안쪽(`N`) |

## 2. VS Code / Cursor 고속 코드 탐색 & 디버깅 ([[layer-5-ide-coding|Layer 5]])

[[layer-0-base|Layer 0]]에서 `Cmd + 알파벳`으로 쉽게 누를 수 있는 단순 단축키(`⌘P`, `⌘B`, `⌘D`)는 기본 레이어에서 누르고, 왼손 약지로 `X` 키를 홀드하면 **왼손은 디버깅 풀패드**, **오른손은 코드 탐색 패드**로 동작합니다.

### ① 코드 흐름 따라가기 (오른손 상단 + 홈 로우)
1. **정의/구현체 들어가기**: 함수 위에서 `X + U`(`F12` 정의 이동) 또는 `X + I`(`⌘F12` 구현체 이동), 살짝만 보려면 `X + Y`(`⌥F12` 미리보기)
2. **원래 보던 곳으로 복귀**: 코드를 확인한 뒤 오른손 홈 로우 `X + H`(`⌃-` 뒤로) / `X + J`(`⌃⇧-` 앞으로)로 즉시 복귀
3. **에러 잡고 자동 고치기**:
   - `X + L`(`F8` 다음 에러) 또는 `X + Enter`(`⇧F8` 이전 에러)로 빨간 줄 위치로 즉시 점프
   - 에러 위에서 `X + Space`(`⌘.` Quick Fix)를 눌러 자동 Import 또는 수정 적용
4. **함수 목록 & 괄호 점프**:
   - `X + K`(`⌘⇧O`): 현재 파일 내 함수/메서드 목록 점프
   - `X + Bksp`(`⌘⇧\`): 긴 함수나 조건문의 시작 `{` ↔ 끝 `}` 짝꿍 괄호 점프

### ② 스텝 디버깅 (왼손 중단 + 상단)
1. **중단점 찍고 실행**: `X + A`(`F9` 중단점) → `X + S`(`F5` 디버그 실행)
2. **한 줄씩 추적 (중지·검지 `D, F, G`)**:
   - `X + D` (`F10`): **Step Over** (현재 줄 실행 후 다음 줄로)
   - `X + F` (`F11`): **Step Into** (호출된 함수 내부로 진입)
   - `X + G` (`⇧F11`): **Step Out** (현재 함수를 끝내고 호출부로 탈출)
3. **디버그 창 & 세션 제어 (상단 `Q~T`)**:
   - `X + E`(`⌘⇧D` 변수/콜스택 창), `X + R`(`⌘⇧Y` 디버그 콘솔), `X + W`(`⌘⇧F5` 재시작), `X + Q`(`⇧F5` 디버그 중지)

### ③ 줄 단위 편집 & 포맷팅 (오른손 하단)
- `X + N` (`⌘/`): 주석 토글
- `X + M` / `Tab` (`⌥↓` / `⌥↑`): 현재 줄 아래·위로 이동
- `X + Caps` (`⇧⌥↓`): 현재 줄 아래로 복제
- `X + SftEnt` (`⇧⌥F`): 문서 전체 코드 포맷팅
- `X + 왼손 B` (`⌘⇧K`): 현재 줄 통째로 삭제
