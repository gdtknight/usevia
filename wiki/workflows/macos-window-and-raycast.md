# 🚀 macOS 창 관리(Rectangle) · 시스템 제어 워크플로우

macOS 환경에서 초경량 창 분할 앱인 **Rectangle**과 화면 캡처·화상회의 제어를 [[layer-3-mouse-media|Layer 3]], [[layer-6-hyper-meh|Layer 6]], [[layer-8-macos-system|Layer 8]]로 분담하는 워크플로우입니다.

---

## 1. 무설정(Zero-Config) Rectangle 창 분할 ([[layer-6-hyper-meh|Layer 6]])

[[layer-6-hyper-meh|Layer 6]](`왼손 하단 C 홀드`)에는 **Rectangle의 기본 단축키(`⌃⌥ + 키`)**가 이미 내장되어 있어, Rectangle 설치 후 별도 단축키 설정 없이 즉시 작동합니다.

### 핵심 창 배치 동선 (`C` 홀드 + 오른손)
- **좌/우 절반 분할**: `C` + 오른손 **`H` / `L`** (`⌃⌥←` / `⌃⌥→`)
- **상/하 절반 분할**: `C` + 오른손 **`K` / `J`** (`⌃⌥↑` / `⌃⌥↓`)
- **창 최대화 (꽉 채우기)**: `C` + 오른손 **`Bksp`** (또는 오른손 하단 끝 `SftEnt`, `⌃⌥Enter`)
- **정중앙 배치 / 원래 크기 복구**: `C` + 오른손 엄지 **`Space`(`⌃⌥C`) / `Enter`(`⌃⌥⌫`)**
- **4분할 모서리**: `C` + 오른손 상단 **`U`(좌상) / `I`(우상) / `O`(좌하) / `P`(우하)**
- **멀티 모니터 간 창 이동**: `C` + 오른손 하단 **`N`(이전 모니터 `⌃⌥⌘←`) / `M`(다음 모니터 `⌃⌥⌘→`)**
- **와이드 모니터 3분할**: `C` + 왼손 **`D`(좌 1/3) / `F`(중 1/3) / `G`(우 1/3)** 및 **`E`(좌 2/3) / `T`(우 2/3)`**

## 2. Spaces(가상 데스크탑) 전환 & 멀티 모니터 포커스 원리 ([[layer-3-mouse-media|Layer 3]])

- 오른손 바깥 엄지(`MO(3)`)를 누른 채 왼손 홈 로우 `A / F`를 누르면 좌우 전체화면 앱/데스크탑(`⌃← / ⌃→`)을 즉시 전환하고, `D`를 누르면 미션 컨트롤(`⌃↑`)이 열립니다.
- 간단한 팝업 닫기나 버튼 클릭은 마우스로 손을 옮기지 않고 Layer 3 오른손 홈 로우(`H,J,K,L`)와 엄지(`좌/우클릭`)로 즉시 해결합니다.

> [!IMPORTANT]
> **듀얼/멀티 모니터에서 `⌃← / ⌃→` 데스크탑 전환 시 핵심 주의사항**:
> 1. **macOS는 "활성 창"이 아니라 "마우스 커서가 있는 모니터"의 데스크탑을 전환합니다**:
>    - 1번 모니터의 창에 키보드 포커스가 있더라도, **마우스 화살표가 2번 모니터에 가 있으면 `⌃← / ⌃→`를 눌렀을 때 2번 모니터의 데스크탑이 넘어갑니다.**
> 2. **현재 활성 모니터를 눈으로 확인하는 법**:
>    - 각 모니터 최상단 **메뉴 막대(Menu Bar, 🍎 아이콘 및 시계 줄)**를 보면, **현재 활성화된 모니터는 글씨가 100% 선명(불투명)**하고 **비활성 모니터는 반투명하게 흐려져(Dimmed)** 있습니다.
> 3. **Rectangle 필수 연동 설정 (`moveCursorAcrossDisplays`)**:
>    - Rectangle 설정(⚙️ 톱니바퀴 탭)에서 **"디스플레이 간에 창과 함께 커서 이동 (Move cursor along with window across displays)"**을 켜두면(또는 `defaults write com.knollsoft.Rectangle moveCursorAcrossDisplays -bool true`), Layer 6(`C + N/M`)으로 창을 다른 모니터로 보낼 때 마우스 커서도 함께 따라가서 데스크탑 전환 모니터가 꼬이지 않습니다.

## 3. 캡처 · 잠금 · 화상회의 원터치 제어 ([[layer-8-macos-system|Layer 8]])

오른손 하단 `M` 키를 홀드한 상태에서 왼손으로 실행합니다:
- **화면 캡처 3종**: `M + W`(전체 `⌘⇧3`), `M + E`(영역 `⌘⇧4`), `M + R`(도구 모음 및 화면 녹화 `⌘⇧5`)
- **자리 비움 보안**: `M + Q`(`⌃⌘Q`)로 즉시 맥 잠금 화면 진입
- **이모지 입력기**: `M + T`(`⌃⌘Space`)
- **Zoom / 화상회의**: `M + Z`(마이크 음소거 토글 `⌘⇧A`), `M + X`(카메라 토글 `⌘⇧V`)
